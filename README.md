# cashlyctl

Terminal operations console and CLI for Cashly/DealSense deployments.

This repository is the initial template for MVP-1:

- Primary Option Menu and profile picker
- Systems Status and Neo4j Console shell panels
- Mocked health checks (OK/WARN/FAIL)
- Shared config/session/audit foundations for future connectors
- Slanted ASCII splash generated by pyfiglet (text-driven, no hand-tuned glyphs)

## Quick Start

```bash
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .
cashlyctl console
```

Default logon (dev template): `admin / cashly123` from local `.env`.

## CLI

```bash
cashlyctl console
cashlyctl profile list
cashlyctl health
cashlyctl health --profile local-dev
```

## Local State

`cashlyctl` stores files under `~/.cashlyctl/`:

- `config.toml`
- `catalog/`
- `queries/`
- `state/`
- `logs/`

On first run, it creates a starter config with `local-dev` and `enterprise-stage`.

## Login Credentials

Login credentials are loaded from `.env` entries:

- `CASHLYCTL_LOGIN_ADMIN=cashly123`

Command usage in console:

- `LOGON admin cashly123`
- `L admin cashly123`

Optional ASCII logo settings via env vars:

- `CASHLYCTL_ASCII_TEXT=cashlyCTL`
- `CASHLYCTL_ASCII_FONT=slant`
